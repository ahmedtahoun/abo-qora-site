# Abo Qora — demo site

Published copy of the clickable prototype for **Abo Qora Kababgy**, deployed to cPanel with Git.

- `index.html`: the ordering site
- `admin.html`: the admin panel (demo logins on its sign-in screen)

Payments and WhatsApp messages are simulated. Data stays in the visitor's browser.

> Don't edit this repo directly. It's generated from the private `abo-qora` repo by `npm run publish:site`.
